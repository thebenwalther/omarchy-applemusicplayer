# Security Policy

## Supported versions

Security fixes are applied to the latest release. Older tags, including the archived MusicKit prototype, are unsupported.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability or include Apple credentials, browser data, tokens, or private keys in any report.

Use GitHub's **Report a vulnerability** flow on the repository Security page. Include the affected version, impact, reproduction steps that do not expose personal data, and any suggested mitigation. Reports will be acknowledged as soon as practical and coordinated privately until a fix is available.

The current supported architecture stores no Apple credentials and runs no project-owned background service.
